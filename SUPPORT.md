# Getting Help

- **Questions and setup help:** use GitHub Discussions.
- **Bugs:** open an issue with the bug report form.
- **Ideas:** start in Discussions, then open a feature request once the problem is
  clear.
- **Security issues:** never in public. Follow [SECURITY.md](SECURITY.md).

Signal is maintained by one person. Replies may take a few days; issues with a
clear reproduction get answered first. A managed, supported service is planned
separately from this repository.
